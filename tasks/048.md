# 048 — Known-ATS field maps (Greenhouse, Lever, Ashby, Workday)

**Status:** TODO | **Milestone:** M6

## Objective
Stage 1 of the three-stage field-mapping pipeline (`docs/05-playwright-design.md` §4): deterministic selector maps for the four named ATS hosted-form platforms, versioned per ATS, covered by recorded-fixture tests (not live sites — same anti-flake pattern M4's connector fixtures already established).

## Files affected
- `apps/browser-runner/src/ats-maps/{greenhouse,lever,ashby,workday}.ts` (new) — each exports a versioned selector map: canonical taxonomy field (name, email, phone, resume-upload, work-auth, EEO questions, ...) → CSS/ARIA selector, plus a `detect(page): boolean` (or DOM signature) to identify which adapter applies to a given form.
- `apps/browser-runner/src/ats-maps/taxonomy.ts` (new) — the canonical field taxonomy shared by this task, 049 (heuristics), and 050 (LLM mapper) — define this once here since 048 is the first consumer, 049/050 depend on it.
- `apps/browser-runner/test/fixtures/{greenhouse,lever,ashby,workday}/*.html` (new) — recorded/sanitized HTML snapshots of real hosted application forms (mirror M4's `packages/*/test/fixtures` recorded-fixture pattern for connectors).
- `apps/browser-runner/test/ats-maps.spec.ts` (new) — Playwright tests loading each fixture and asserting every selector in the map resolves to the expected field.

## Dependencies
- 047 (browser-runner scaffold + Playwright).

## Acceptance criteria
- Each of the 4 ATS maps resolves 100% of its declared taxonomy fields against its own fixture set (a map claiming to detect a field but failing against its own fixture is worse than not claiming it).
- `detect()` correctly identifies which adapter applies and returns false/no-match for the other 3 platforms' fixtures (no false-positive adapter selection).
- Sensitive-field policy from §4 is respected at the taxonomy level: EEO/demographic/veteran/disability fields are tagged `neverAutoFill: true` in the taxonomy, not silently mappable.

## Test plan
- Playwright fixture tests (this task's own `ats-maps.spec.ts`) — the primary proof, per `docs/05-playwright-design.md` §7's testing table ("Selector maps | Playwright tests against recorded HTML fixtures per ATS version").
