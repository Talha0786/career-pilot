# 060 — Interview prep pipeline + company research

**Status:** TODO | **Milestone:** M7

## Objective
Implement `generate_interview_prep` (§3 table) backed by the two interview-prep pipelines from `docs/06-agent-design.md` §3/§5: "Interview Q&A generation | pipeline | mid | QuestionSet schema" and "Company research | bounded tool loop (max 8 tool calls): web search/fetch → synthesize brief with citations. No write tools. Output schema-validated; uncited claims dropped."

## Files affected
- `packages/contracts/src/interview-prep.ts` (new) — `QuestionSetSchema`, `CompanyResearchBriefSchema` (with a `citations` field per question/claim).
- `prompts/interview-questions/v1.md`, `prompts/company-research/v1.md` (new) — following the M5 `prompts/{task}/{version}.md` convention (034).
- `packages/application/src/interview-prep/commands/generate-questions.ts` (new) — deterministic pipeline: JD + profile facts (reuse M5 task 037's `compileFactList`) → guarded `llm.complete()` → `QuestionSetSchema` validate → one repair attempt → typed failure, same ADR-006 discipline as every prior LLM call site.
- `packages/application/src/interview-prep/commands/research-company.ts` (new) — the bounded tool loop: max 8 tool calls, web search/fetch tools (new — check if any existing infra has a web-fetch adapter; if not, build a minimal one scoped read-only to this pipeline), synthesizes a brief, drops any claim without a citation (schema-enforced, not just prompted — reject/strip uncited claims post-validation, mirroring M5 task 040's adversarial-verification rigor for the anti-hallucination contract, applied here to "must cite a source" instead of "must cite a profile fact").
- `apps/mcp-server/src/tools/generate-interview-prep.ts` (from 058, or add here if 058 stubbed it) — wires `{applicationId, kind: 'questions' | 'company_research'}` to the two commands above.
- `packages/infrastructure/src/db/migrations/0008_interview_preps.sql` (new) — `interview_preps` table (also used by 061's mock-interviewer transcripts — design the schema to cover both: `{id, application_id, kind, content jsonb, created_at}` where `kind` distinguishes `questions`/`company_research`/`mock_interview_transcript`).

## Dependencies
- 056 (MCP scaffold, though this task's commands are usable directly from application layer independent of MCP), M5 task 037 (fact-list compilation), M3 (CareerProfile).

## Acceptance criteria
- Company research brief never contains an uncited claim — test with a deliberately fabricating fake LLM response, confirm the uncited claim is stripped, not passed through.
- Tool loop is hard-capped at 8 calls (test: a pathological "keep searching forever" fake tool response still terminates at 8).
- No write tools are reachable from the research loop (read-only, per the design doc).

## Test plan
- Unit: uncited-claim-stripping with a fake LLM; tool-loop 8-call hard cap with a fake tool that always requests another call.
- Integration: real Postgres persistence of `interview_preps` rows; MCP tool round trip.
